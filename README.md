# Amazon-Clone
 A pixel-perfect Amazon home page clone built with HTML and CSS to practice complex layouts, following the tutorial by Shraddha Ma'am (Apna College).
 <br>
🛒 Amazon Clone( E-commerce-UIClone,HTML & CSS)
<br>
A responsive front-end clone of the Amazon homepage built using HTML and CSS. This project focuses on layout design, styling, and replicating a real-world e-commerce UI
<br>

This is a fronted UI practice project. No real data is collected.
<br>
